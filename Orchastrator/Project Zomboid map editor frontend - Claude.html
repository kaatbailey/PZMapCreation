What was wrong

main.py render base_top PZGisImport doesn't mean "render base_top for PZGisImport". pzmap2dzi's render() loops over its arguments as render jobs:

python
for cmd in args.args:          # 'base_top', then 'PZGisImport'
    if conf.get('base_map'): render_map(cmd, ..., conf['base_map'])
    for map_name in conf['mod_maps']: render_map(cmd, ..., map_name, 'mod')

Valid jobs are base, base_top, rooms, zombie, foraging, objects, streets, save… — never a map name. The maps come from conf.yaml's base_map and mod_maps.

So your command ran base_top against whatever's in mod_maps (PZGisImport), then hit PZGisImport as a second job and printed unspported render cmd. Exit 0. My step called that success.

It only ever worked because PZGisImport was already in that list. Simmons never had a chance.

What I changed

Before rendering, the orchestrator now registers the mod:

  • conf/mod/pzorch_maps.txt — the map entry. Absolute map_path, because the stock B42 template is {mod_root}/{steam_id}/mods/… and assumes a Workshop mod; yours live under ~/Zomboid/mods. This file is entirely mine, and conf.yaml already globs conf/mod/.
  • conf/conf.yaml — one line into mod_maps:. Patched as text, not via PyYAML, because a round-trip would wipe the ~200 lines of comments in that file. I verified all 118 comment lines survive byte-identical and exactly one line is added. It takes a .pzorch-bak on first touch and is idempotent.

Then main.py -c <conf> render base_top — no map name — and the job fails unless it sees render [base_top] for map [SimmonArmyAirfield] done and finds tiles on disk.

One thing the tests caught: my first guard failed the whole job when any mod in the shared mod_maps list was misconfigured. Another mod's problem isn't your render's problem, so that's a warning now.

Worth knowing

Your 286 cells across a 22×13 grid is a big map, and the roof tally is lopsided: 1143 flat (commercial/tall class) vs 144 pitched. For an airfield that's plausible — hangars and admin blocks — but §G's open bug means any building taller than wide is emitting east-west slope sprites on a north-south ridge. Worth a look once you can see it.

Also: dzi_cell_range[default]: all_mod_maps in your conf means the base DZI extent is the union of all mod maps. Placing Simmons far from PZGisImport will make base tiles stale and trigger a re-render of the base at the new extent. Incremental, so probably seconds — but if step 4 ever takes minutes instead, that's why.
